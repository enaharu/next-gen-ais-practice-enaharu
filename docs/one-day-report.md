## 目的

- 仕事後も頭に残る不安、怒り、悔しさなどを短時間で手放すきっかけを作るサービス。
- 日記やタスク管理ではなく、「書いて燃やす」体験を通して感情の客観視や解放感を目的とする。
- ログインやデータ保存を必要とせず、帰宅後や就寝前に「気軽に」使える構成にする。
- PCとスマートフォンの両方で体験でき、GitHub Pagesで公開可能な状態まで整備する。

## アプリ概要

ユーザーが「今日のモヤモヤ」を200文字以内で入力すると、その言葉を書いた紙が焚き火で燃え、灰になるというアニメーションを演出。
燃焼後は入力内容に応じた短いメッセージを表示し、「気持ちが軽くなった」ボタンから初期状態へ戻る。

画面遷移は行わず、次の3段階を1ページ内の状態切り替えにて実装。

1. 入力: 手放したい気持ちを書き出す。
2. 燃焼: 紙が焚き火で燃えて灰になるアニメーションを表示。
3. 完了: 気持ちに応じたメッセージを受け取り、体験を終了する。

## 1人日の使い方

実質7.5時間を次のように配分しました。

1. 要件整理・方針検討（1.0時間）
   - クライアントが何を求めているのか明確にするため、ヒアリングの準備
   - ヒアリングの想定回答に応じて、1人日で作成できるサービスの概要を検討
2. ヒアリング・コンセプト決定（0.5時間）
   - ヒアリングを行い、「帰宅後」に「簡単で手軽な操作」で、「仕事との区切り」が行えるサービスを求めていることがわかった
   - 簡単な操作体験で悩みに直接働きかけ、1人日で完成させやすい「デジタル焚き火」を採用
3. UI・体験設計（1.0時間）
   - 入力、燃焼、完了の3段階に操作を限定
   - 静かな雰囲気の中に焚き火の暖かさを感じるシンプルなデザインを設計
   - PCは3カラム、スマートフォンは段階ごとに表示を切り替える構成を採用
4. 基本機能の実装（1.0時間）
   - それぞれのカラムの基本機能を実装
   - 200文字までのテキスト入力、未入力時の送信防止、文字数表示、プレースホルダーを実装
   - 体験を繰り返せるリセット処理を実装
4. 燃焼アニメーションの実装（2.5時間）
   - ウェブ上で焚き火のアニメーションを再現しようと思ったが、クオリティが伴わなかったため、最終的に動画素材を使用した
   - 紙の焦げ、穴、文字の消失、灰、火の粉などの演出を追加
5. レスポンシブ対応・仕上げ（0.5時間）
   - 画面幅900pxを境にPC用とモバイル用のレイアウトを切り替え
   - 入力内容のキーワードに応じて完了メッセージを変える処理を追加
   - ファビコン、ホーム画面用アイコンを登録
6. 検証・ドキュメント整備（1.0時間）
   - デモサイトでの動作確認
   - 1人日作業報告を作成

## 工夫した点

- 入力内容はバックエンドやブラウザへ保存せず、フロントエンドのみで完結する設計にした。
- 単なる削除ではなく、紙が徐々に燃えて消える演出を見せることで「手放した」という実感を作った。
- 長文入力や複雑な設定を避け、疲れているときでも簡単に操作できることを意識して実装した。
- 不安、怒り、失敗、疲れなどのキーワードに応じて、完了時のメッセージを出し分けた。
